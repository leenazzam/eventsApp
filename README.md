
# 🎉 Event Management App

A Flutter application for creating and managing events with Firebase integration.  
Users can add, delete, and favorite events with support for multiple languages and themes.

## ✨ Features
- Firebase Authentication
- Cloud Firestore
- Add & Delete Events
- Favorite Events
- Arabic & English Support
- Light & Dark Theme
- Provider State Management

## 🛠️ Technologies
- Flutter & Dart
- Firebase Authentication
- Cloud Firestore
- Provider
- Intl
