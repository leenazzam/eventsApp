# Event Management App

A Flutter application for creating and managing events with Firebase Authentication and Cloud Firestore.

## Features
- Firebase Authentication
- Cloud Firestore
- Add & Delete Events
- Favorite Events
- Arabic & English
- Light & Dark Theme
- Provider State Management

## Technologies
- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Provider
- Intl
